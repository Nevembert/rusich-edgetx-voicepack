# «Русич» для EdgeTX — создано с elevenlabs.io

Первая публичная версия русской некоммерческой озвучки:

- 25 системных предупреждений EdgeTX;
- 52 назначаемых фразы;
- WAV PCM 16-bit, 32 kHz, mono;
- высота голоса не изменялась;
- готовая структура `SOUNDS/ru`.

Скачайте `Rusich_EdgeTX_Boxer_ready.zip`, распакуйте его и скопируйте папку `SOUNDS` в корень SD-карты пульта.

Перед заменой сделайте резервную копию оригинальной папки `SOUNDS`. После установки проверьте критические предупреждения на земле.

Озвучено с помощью [ElevenLabs](https://elevenlabs.io/), голос Nester Surovy. Только для личного некоммерческого использования.
