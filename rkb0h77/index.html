    02 / УСТАНОВКА

    Из портала в пульт

    WAV · PCM 16 бит · 32 кГц · моно

    Пакет предназначен для пультов с EdgeTX. У T8L на иллюстрации своя прошивка.

    Руководство EdgeTX ↗

    1. Скачай архив

      Сохрани копию папки SOUNDS на SD-карте. Установи полный русский звуковой пакет для своей версии EdgeTX, затем распакуй этот ZIP и объедини папки SOUNDS с заменой совпадающих файлов. Остальные звуки русского пакета понадобятся для чисел и единиц измерения.

    2. Выбери русский язык голоса

      В настройках пульта установи русский в пункте Voice language. Системные записи лежат в SOUNDS/ru/SYSTEM.

    3. Назначь фразы на переключатель

      В настройках модели открой Special Functions, выбери условие срабатывания и действие Play Track. Укажи нужную реплику и включи функцию.

    03 / НАСТРОЙКА

    Голос на тумблере

    Назначения сохраняются отдельно для каждой модели. Для примера используем трёхпозиционный тумблер SB.

    Специальные функции EdgeTX ↗

    1. Проверь положения тумблера

      В Betaflight открой Receiver и Modes, чтобы сопоставить тумблер, AUX-канал и режимы. В обычной настройке Acro включён, когда ANGLE и HORIZON выключены. Подставь свои положения в пример ниже.

    2. Создай отдельную строку для каждого положения

      На Pocket или Boxer открой MDL → нужная модель → PAGE> → Special Functions. В каждой свободной строке выбери положение тумблера, действие Play Track и дорожку. Если есть флажок включения, отметь его.

      Пример назначений для SB
      ТумблерРежимДорожка
      SB↑Acrofm-acr
      SB–ANGLEfm-ang
      SB↓HORIZONfm-hor

    3. Выбери повтор и проверь звук

      - или 1x проигрывает фразу один раз при активации. !- или !1x пропускает её при включении пульта. WAV для назначения должны лежать прямо в SOUNDS/ru/. Сними пропеллеры и проверь все положения на земле. Фраза сообщает о положении тумблера, а фактический режим показывает полётный контроллер.

    Для режимов самого EdgeTX можно выбрать FM0 или FM1 в поле переключателя Special Functions. Для FM1 и последующих режимов сначала задай переключатель на странице Flight Modes.

    Для команды арминга есть armed и disarm, для возврата — fm-rth. Фактический арминг и запуск возврата проверяй по данным полётного контроллера.
