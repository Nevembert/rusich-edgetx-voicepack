# ЗЕТ: Раскол — Arc Warden × EdgeTX

Новый фанатский проект русской озвучки пульта для игрока на Арк Вардене. Основа — [«Русич»](https://github.com/Nevembert/rusich-edgetx-voicepack), сохранены все **77 имён файлов: 25 системных и 52 назначаемых**.

**Статус: сценарий и сайт готовы; голос ещё не записан. WAV и готового установочного архива пока нет.** Это новые реплики для пульта, а не оригинальные реплики из Dota 2. Скрипт обработки не умеет превращать произвольный голос в точную копию персонажа.

## Что уже есть

- [Полный сценарий](PHRASES.md) и машиночитаемый `manifest.json`.
- [Задание на голос](VOICE-BRIEF.md): тембр, подача, шесть пробных реплик.
- Сайт в `dist/`: поиск, категории, копирование текстов, воспроизведение настоящих записей по мере их добавления, скачивание исходников.
- `tools/voicepack.py`: пакетная генерация с выбранным голосом ElevenLabs, обработка через FFmpeg, проверка формата и сборка ZIP.
- Тесты блокировки пустого/неправильного аудио и неполной сборки.
- GitHub Actions для проверки проекта и отдельный workflow публикации сайта через Pages.

## Дальнейший порядок

1. Выбрать источник русской озвучки Арк Вардена. Сам по себе текстовый промпт не обеспечивает нужный голос. Возможны выбранная модель голоса или отдельно подготовленные записи.
2. Сделать шесть пробных файлов по `VOICE-BRIEF.md`, прослушать их и проверить разборчивость на пульте.
3. Озвучить все 77 реплик. Если на исходнике уже есть игровая обработка, использовать `--effect none`.
4. Запустить обработку и строгую проверку. Добавить получившиеся WAV в Git, обновить сайт.
5. Уточнить модель пульта друга, версию EdgeTX и проверить назначения на земле.

## Инструменты

Нужны Python 3.10+ и FFmpeg в PATH. Python-библиотеки устанавливать не требуется. Команды выполняются из корня проекта; на Windows вместо `python` можно использовать `py`.

Проверить сценарий без генерации и расхода квоты:

```bash
python tools/voicepack.py generate --preview --dry-run
```

Для генерации задайте `ELEVENLABS_API_KEY` и `ELEVENLABS_VOICE_ID` **локально в окружении**, затем выполните:

```bash
python tools/voicepack.py generate --preview
```

Скрипт использует явно выбранный голос, `eleven_multilingual_v2` и выход MP3. Он не создаёт/не выбирает клон автоматически. Сохранённые MP3 пропускаются; повторно сгенерировать их можно с `--overwrite`. Реальный запрос расходует квоту аккаунта. API-вызовы здесь не выполнялись: интеграция ожидает выбранного голоса и проверки с аккаунтом.

Сторонние записи можно просто положить в `raw/`, например `raw/armed.mp3` и `raw/SYSTEM/hello.wav`.

```bash
python tools/voicepack.py convert --preview --effect none
```

Для сухого исходного голоса доступен экспериментальный эффект второго слоя: `--effect dual`. Он ослаблен и выключен на предупреждениях. Он не заменяет правильный исходный тембр и не гарантирует сходство с игровым голосом.

После утверждения пробников:

```bash
python tools/voicepack.py generate
python tools/voicepack.py convert --effect none
python tools/voicepack.py validate --require-complete
python tools/voicepack.py build-site
python tools/voicepack.py source-zip
```

Полный архив появится как `dist/ArcWarden_EdgeTX_ru.zip` только после успешной проверки всех записей. Формат: WAV PCM 16-bit, 32 kHz, mono. Проверка оценивает формат, длительность, цифровой клиппинг и тишину; правильность текста и качество голоса проверяются прослушиванием.

## Сайт и GitHub

Сценарий пока опубликован в отдельной ветке [`arcwarden`](https://github.com/Nevembert/rusich-edgetx-voicepack/tree/arcwarden). Ветка `main` содержит «Русича».

Для локального просмотра откройте `dist/index.html`: каталог загружается без сервера. GitHub Pages workflow рассчитан на **отдельный репозиторий** с этим проектом. Он намеренно запрещает публикацию из репозитория «Русича», чтобы один Pages-сайт не подменил другой. Для переноса скачайте `ArcWarden_Project_Source.zip`, создайте `arcwarden-edgetx-voicepack`, загрузите содержимое корневой папки и выберите GitHub Actions в Settings → Pages.

## Совместимость

Набор дополняет установленный русский пакет EdgeTX: он не содержит всех числительных, единиц измерения и всех звуков прошивки. Системные имена взяты из «Русича»; срабатывание каждого события зависит от прошивки, датчиков и оборудования. [Установка и назначения](INSTALL.md).

Код — MIT. [О происхождении будущего аудио](AUDIO-NOTES.md). Проект не связан с Valve, EdgeTX или RadioMaster.
