# «Русич» — русская озвучка EdgeTX, созданная с ElevenLabs

Любительский некоммерческий набор из **77 русских фраз** для аппаратуры на EdgeTX, включая RadioMaster Boxer. Внутри — системные предупреждения и отдельные звуки, которые можно назначать на логические переключатели и специальные функции.

## Послушать и скачать

После публикации GitHub Pages здесь будет доступна страница с предпрослушиванием:

**https://nevembert.github.io/rusich-edgetx-voicepack/**

Готовый установочный архив: [Rusich_EdgeTX_Boxer_ready.zip](https://github.com/Nevembert/rusich-edgetx-voicepack/releases/latest/download/Rusich_EdgeTX_Boxer_ready.zip)

## Что внутри

- `SOUNDS/ru/SYSTEM/` — 25 системных звуков EdgeTX;
- `SOUNDS/ru/` — 52 назначаемых звука;
- раздел **Releases** — готовый архив с правильной структурой папок;
- `index.html`, `styles.css`, `app.js` — страница предпрослушивания.

Все WAV-файлы подготовлены без изменения высоты голоса:

- PCM signed 16-bit little-endian;
- 32 kHz;
- mono.

## Установка

1. Скачайте `Rusich_EdgeTX_Boxer_ready.zip` и распакуйте его.
2. Выключите пульт и извлеките SD-карту либо подключите пульт в USB-режиме накопителя.
3. Сделайте резервную копию существующей папки `SOUNDS` на SD-карте.
4. Скопируйте папку `SOUNDS` из архива в корень SD-карты, разрешив объединение папок и замену файлов.
5. В EdgeTX выберите русский язык озвучки, если он ещё не выбран.
6. Включите пульт и на земле проверьте системные предупреждения.

> Названия системных файлов должны оставаться неизменными: EdgeTX находит фразы именно по ним.

## Как назначить дополнительные фразы

Откройте настройки модели → **Специальные функции**:

1. выберите переключатель или условие;
2. выберите действие **Воспр. дорожку / Play Track**;
3. укажите нужный файл из `SOUNDS/ru`;
4. задайте режим воспроизведения.

## Совместимость и безопасность

Набор подготовлен для русской локали EdgeTX и RadioMaster Boxer ELRS. На других пультах EdgeTX он также может работать, если прошивка поддерживает WAV PCM 16-bit, 32 kHz, mono.

Это любительский проект, не связанный с EdgeTX или RadioMaster. Не полагайтесь только на голосовые уведомления: перед полётом проверяйте арминг, failsafe, телеметрию, RSSI и заряд аккумуляторов.
