# Установка озвучки «ЗЕТ: Раскол»

Готовый набор: 77 WAV-файлов, 25 системных и 52 назначаемых. Формат — PCM 16-bit, 32 kHz, mono. [Скачать пакет](https://nevembert.github.io/rusich-edgetx-voicepack/segl7hd/ArcWarden_EdgeTX_ru.zip).

1. Сохраните копию папки `SOUNDS` со своей SD-карты.
2. Убедитесь, что уже установлен полный русский пакет звуков для вашей версии EdgeTX.
3. Распакуйте `ArcWarden_EdgeTX_ru.zip` и скопируйте `SOUNDS` в корень SD-карты с объединением папок и заменой совпадающих файлов. Не удаляйте остальные звуки.
4. Выберите русский язык озвучки в настройках пульта.
5. Проверьте приветствие, предупреждение газа, переключатели и уведомление о низком заряде пульта.

## Назначаемые фразы

Настройки модели → Специальные функции → нужный переключатель или логическое условие → «Воспр. дорожку / Play Track» → имя файла.

| Событие | Файл |
| --- | --- |
| Арминг / дизарм | `armed` / `disarm` |
| ACRO / ANGLE / HORIZON | `fm-acr` / `fm-ang` / `fm-hor` |
| Возврат домой | `fm-rth` |
| Низкий / критический заряд борта | `lowbat` / `batcrt` |
| Низкий / критический сигнал | `siglow` / `sigcrt` |

### Пример для трёхпозиционного тумблера

1. В Betaflight → **Modes** проверьте, какой тумблер и какие положения включают ANGLE и HORIZON. В обычной настройке Acro действует, когда оба режима выключены.
2. На пульте откройте **MDL** → нужная модель → **Специальные функции** (**Special Functions**). Создайте отдельную строку **Play Track** для каждого положения. Например, если на вашей модели `SB↑` включает Acro, `SB–` включает ANGLE, а `SB↓` включает HORIZON, выберите соответственно `fm-acr`, `fm-ang` и `fm-hor`.
3. Для однократной фразы укажите повтор `-` (`1x`). Если нужна тишина при включении пульта, используйте `!-` (`!1x`).
4. Снимите пропеллеры и сверьте каждую фразу с режимом в Betaflight Configurator или OSD. Фраза срабатывает от тумблера, а фактический режим показывает полётный контроллер.

Для режимов, настроенных в самом EdgeTX, в поле переключателя можно выбрать активный режим, например `FM0` или `FM1`. Для `FM1` и последующих режимов сначала задайте переключатель в **Flight Modes**.

[Специальные функции EdgeTX](https://manual.edgetx.org/bw-radios/model-select/special-functions) · [Режимы Betaflight](https://betaflight.com/docs/wiki/app/auxiliary-tab)

Пороги батареи и сигнала задаются отдельно для вашей модели; пакет не создаёт их автоматически. Значение Play Track сообщает о назначенном условии и само по себе не подтверждает фактический режим полётного контроллера. Для точного подтверждения нужна соответствующая телеметрия. Потеря телеметрии и потеря управления — разные события.

Проверьте реальные срабатывания на земле с безопасно отключёнными моторами. Проект оформлен для RadioMaster Pocket; перед установкой уточните установленную версию EdgeTX и проверьте назначения своей модели.

Имена в `SYSTEM` оставляйте без изменений. Пакет содержит 77 тематических фраз, но не заменяет все числа, единицы и звуки EdgeTX.

Темп и полные фразы сохранены такими, какими их записал автор. Некоторые предупреждения звучат дольше первоначальной цели 3,5–4 секунды; длительность каждой записи указана в каталоге. Оцените разборчивость и задержку повторных уведомлений на пульте.
