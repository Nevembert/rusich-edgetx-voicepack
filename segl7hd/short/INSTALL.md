# Короткая озвучка Арк Вардена — установка

Этот архив содержит 77 коротких записей: 25 системных и 52 назначаемые.
Формат: WAV PCM 16-bit, 32 kHz, mono.

1. Сохрани резервную копию папки `SOUNDS` с SD-карты пульта.
2. Объедини папку `SOUNDS` из этого архива с папкой на карте. Замени совпадающие файлы, сохрани остальные звуки полного русского пакета EdgeTX.
3. Выбери русский язык озвучки в настройках пульта.
4. Проверь системные уведомления. Для режимов и других пользовательских событий используй «Воспроизвести трек» в специальных функциях своей модели.

Имена файлов совпадают с полной версией: существующие назначения сохранятся. На карте устанавливается одна версия каждого файла; при копировании обоих архивов последняя версия заменит предыдущую. Можно заменить только отдельные WAV по своему вкусу.

Набор дополняет полный русский звуковой пакет EdgeTX: числительные и единицы измерения из базового пакета нужно сохранить. Проверь звучание и срабатывание уведомлений на земле перед полётом.

Полная версия и каталог: https://nevembert.github.io/rusich-edgetx-voicepack/segl7hd/
Короткие записи: https://nevembert.github.io/rusich-edgetx-voicepack/segl7hd/#short
