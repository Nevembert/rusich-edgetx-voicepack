# ЗЕТ: Раскол — тексты озвучки

Тексты 77 записанных реплик. Учтены изменения автора при генерации в Fish Audio. Это фанатская адаптация под Arc Warden, не оригинальные реплики из Dota 2.

## Пульт и подготовка

| Файл | Событие | Текст |
| --- | --- | --- |
| `SYSTEM/hello.wav` | Приветствие | Самость пробудилась. |
| `SYSTEM/thralert.wav` | Газ | Газ не убран. Опусти стик, смертный. |
| `SYSTEM/swalert.wav` | Переключатели | Проверь переключатели. Самость требует порядка. |
| `SYSTEM/lowbatt.wav` | Питание пульта | Заряд пульта низкий. Самость слабеет. |
| `SYSTEM/inactiv.wav` | Бездействие | Пока ты стоишь, Самость теряет возможности. |
| `SYSTEM/eebad.wav` | Память | Ошибка памяти пульта. Раскол Самости. |
| `SYSTEM/modelpwr.wav` | Питание модели | Приёмник ещё включён. Самость ждёт. |
